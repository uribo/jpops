# jpops 0.0.0.9000

- Breaking: `.area = "city"` no longer returns its former mixture of overlapping parent and child areas, which totaled 216,981,681 people in the 2020 Census (`gender = "総数"`), or 1.7201 times the national population of 126,146,099. It is deprecated for one release and now returns exactly the non-overlapping `"municipality"` result. Because this changes results rather than only the spelling of an argument, the deprecation warning is emitted on every call rather than throttled. No option preserves the former result set; use `.area = "all"` and filter explicitly if it is required.
- Added canonical `.area` values `"municipality"` and `"ward"`. `"municipality"` keeps designated cities and Tokyo's special-ward area as single units, whereas `"ward"` replaces them with their individual wards; both exclude year-2000 historical municipalities.
- Added per-`statsDataId` e-Stat area-metadata fetching and caching. Hierarchical filters fetch metadata only when needed, validate and normalize its parent-child graph, and verify that every population area code is covered even when normalized metadata is read from cache.
- The 2015 e-Stat metadata incorrectly assigns the five Kumamoto City wards to Kumamoto Prefecture instead of Kumamoto City. jpops repairs this narrowly defined upstream defect, emits a `jpops_area_meta_repair_warning`, and preserves the raw and repaired parents for audit.
